# Claude transcript source selection

A caller can explicitly assign SSH sessions to remote Agents and omit the host mirrors. `TOKSCALE_CLAUDE_REMOTE_MIRROR_ROOT` selects one absolute Claude projects root whose direct `ssh-<UUID>` subdirectories are excluded. UUIDs must have hexadecimal 8-4-4-4-12 form (case insensitive); arbitrary SSH project names remain included. Existing roots are also canonicalized for path aliases. Relative roots are ignored.

The bounded rule filters live parsing in both the streaming and `parse_local_clients` paths, plus frozen cached sources and retained missing-file history. This keeps `clients --json` message counts, wiki report input and `wrapped --include-agents` consistent with model/graph source selection. Cached-only replay remains specific to persistent model/graph collection. It does not require an unbounded directory list or deleted folders to remain on disk. This is source selection, not event deduplication: the caller opts into assigning all of these SSH mirrors to remote Agents and must ensure those originals are collected independently. The scanner does not detect WSL ownership or supplement an original from an excluded mirror. Removing the selection restores retained observations; ordinary deleted sessions still follow normal cache pruning. Desktop conversation IndexedDB records are outside this transcript policy.

An explicit `--home` ignores the selection, preserving isolated original-source scans. Model JSON and `graph` JSON advertise `claudeSourceExclusions: true`. Consumers must verify that contract before excluding another source from their aggregation. Windows UNC lifecycle behavior still requires native acceptance.
